# Phase 3 — Core Business Workspace

## Goal
Build the working productivity suite that computer shop operators use daily — CRM, Document Engine, Dashboard, Reports, and Shop Settings.

---

## 1. Objectives

| Objective | Deliverable |
|-----------|-------------|
| Customer CRM | Full CRUD, search, import/export, timeline |
| Document Engine | Document generation by type + PDF output + management |
| Shop Dashboard | Live stats, recent activity, quick action buttons |
| Shop Settings | Profile editor, business hours, logo upload |
| Reports | Daily/operator/customer/document reports |

## 7. Routes

```php
// Customers
$router->group(['prefix' => 'customers', 'middleware' => ['auth', 'shopScope', 'csrf']], function($router) {
    $router->get('/', 'CustomerController@index');
    $router->get('/create', 'CustomerController@create');
    $router->post('/', 'CustomerController@store');
    $router->get('/{id}', 'CustomerController@show');
    $router->get('/{id}/edit', 'CustomerController@edit');
    $router->post('/{id}', 'CustomerController@update');
    $router->post('/{id}/delete', 'CustomerController@destroy');
    $router->get('/{id}/timeline', 'CustomerController@timeline');
    $router->post('/import', 'CustomerController@import');
    $router->get('/export', 'CustomerController@export');
    $router->get('/search', 'CustomerController@search');
});

// Documents
$router->group(['prefix' => 'documents', 'middleware' => ['auth', 'shopScope', 'csrf']], function($router) {
    $router->get('/', 'DocumentController@index');
    $router->get('/create', 'DocumentController@create');
    $router->get('/create/{customer_id}', 'DocumentController@create');
    $router->post('/', 'DocumentController@store');
    $router->get('/{id}', 'DocumentController@show');
    $router->get('/{id}/download', 'DocumentController@download');
    $router->post('/{id}/void', 'DocumentController@void');
    $router->post('/{id}/regenerate', 'DocumentController@regenerate');
    $router->get('/{id}/history', 'DocumentController@history');
});

// Reports
$router->group(['prefix' => 'reports', 'middleware' => ['auth', 'shopScope']], function($router) {
    $router->get('/', 'ReportController@index');
    $router->get('/daily', 'ReportController@daily');
    $router->get('/customers', 'ReportController@customers');
    $router->get('/documents', 'ReportController@documents');
    $router->get('/operators', 'ReportController@operators');
    $router->get('/export/{type}', 'ReportController@export');
});

// Settings
$router->group(['prefix' => 'settings', 'middleware' => ['auth', 'shopScope', 'csrf']], function($router) {
    $router->get('/', 'ShopController@settings');
    $router->post('/', 'ShopController@updateSettings');
    $router->post('/logo', 'ShopController@updateLogo');
    $router->post('/hours', 'ShopController@updateHours');
});

$router->get('/shop/switch/{id}', 'ShopController@switchShop');
```

## 9. Tenant Isolation

All customer/document queries scoped by `shop_id` via `$tenantAware = true`. File storage: `/storage/shops/{shop_id}/documents/{year}/{month}/`.

## 10. Development Sequence

```
Week 1: Database + Customers CRM
  - Migrations 016-017 (customers, customer_timeline)
  - Customer model + CustomerTimeline model
  - CustomerController (full CRUD + search + import/export)
  - Customer views (list, form, detail, import)
  - empty-state + pagination components

Week 2: Document Engine + Dashboard
  - Migrations 018-019 (documents, document_history)
  - Install dompdf/mPDF
  - Document model + DocumentHistory model
  - DocumentController (create, list, download, void)
  - Document views (create with type selector + PDF preview)
  - Enhanced DashboardController with real stats queries
  - stat-card + timeline components

Week 3: Reports + Settings + Polish
  - Migration 020 (shop_settings), 021 (shop columns)
  - ReportController + 4 report views + export
  - ShopController + settings views
  - Command palette component
  - Fix validation error display on auth layout
  - Add CSRF middleware to all POST routes
  - Full integration testing
```
