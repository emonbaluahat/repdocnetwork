# UI/UX DESIGN — RepDoc Network

Design philosophy: Stripe + Linear + Notion + Canva + VS Code + Apple.
No Bootstrap dashboards. No traditional ERP design. Desktop-first, productivity-first.

---

## 1. DESIGN PRINCIPLES

| # | Principle | What it means |
|---|-----------|---------------|
| 1 | **Clarity over density** | Every screen has one primary purpose. White space is a feature. |
| 2 | **Keyboard-first** | Power users never need a mouse. CMD+K, shortcuts, tab navigation. |
| 3 | **Speed as a feature** | Optimistic UI, skeleton loading, instant search. Every interaction under 100ms perceived. |
| 4 | **Context everywhere** | Preview panels, slide-in drawers, hover cards. Never lose your place. |
| 5 | **Bangla-first, English-always** | Bangla is default UI language. English toggle available. Documents bilingual. |
| 6 | **Progressive disclosure** | Show basics first. Advanced options behind expand/collapse. Don't overwhelm. |
| 7 | **Offline resilience** | Form data auto-saved. Queue indicator when offline. Nothing lost. |
| 8 | **Consistent command surface** | Every action accessible via CMD+K. Every page has a command. |


Height: 4px (default), 8px (large), 2px (thin)

Steps variant: ○──●──○──○──○ (multi-step form)

### 5.18 Tab Navigation

```

[__________/________________________________]
```

Active tab: primary color + bottom border indicator (2px)
Hover tab: subtle background
Tab count badge: "Documents (24)"
Closeable tabs: for document editing (VS Code style)
Horizontal scroll: if tabs overflow

### 5.19 Filter Bar

```
[ All Status ▼ ] [ Last 7 days ▼ ] [ Operator ▼ ] [ More filters ▼ ]
[ Active filters: Pending | Today | Rahim  × Clear all ]
```

Each filter: dropdown or popover with options
Applied filters: displayed as dismissible tags
Clear all: one click removes all filters
URL-synced: filter state in query parameters (shareable/bookmarkable)

### 5.20 Search (Page-level)

```
[ 🔍 Search by name, phone, NID...  ⚙ Filters ]
```

Debounced (300ms), shows results as you type
Results in dropdown: top 5-10 matches + "View all results"
Search across: customers, documents, orders (configurable per page)
Recent searches remembered (localStorage)
Keyboard shortcut: CTRL+F (page-level), CMD+K (global)

## 10. INTERACTION PATTERNS

### 10.1 Auto-Save
- Forms auto-save draft every 30 seconds
- Indicator: "Draft saved" (green) or "Unsaved changes" (yellow)
- On navigate away: prompt if unsaved
- On browser close: beforeunload if unsaved
- Draft persisted to localStorage + server (when authenticated)

### 10.2 Optimistic UI
- On action (e.g., delete customer): immediately remove from list
- Show undo toast: "Customer deleted. [Undo]"
- If server fails: revert + show error toast
- Applies to: create, update, delete, status changes

### 10.3 Infinite Scroll vs Pagination
- Search results: infinite scroll (virtualized list)
- Tables with actions: pagination (10/25/50/100 per page)
- Timeline: load more button ("Show older activity")
- Customer documents: pagination (for performance with large sets)

### 10.4 Drag & Drop
- Template field reordering
- Custom dashboard widget arrangement
- File upload: drag zone + click
- Sidebar reorder (customization mode)

### 10.5 Batch Actions
- Multi-select items via checkbox column
- Actions appear in floating bar: [Download Selected] [Email Selected] [Delete Selected] [Export Selected]
- Confirm dialog for destructive batch actions

## 12. MICROCOPY GUIDELINES

### Tone
- Professional but warm
- Clear, not cutesy
- Action-oriented
- No jargon

### Examples
| Context | Good | Bad |
|---------|------|-----|
| Empty state | "No customers yet. Add your first customer to get started." | "No records found." |
| Error | "Something went wrong loading customers. Try again." | "Error 500: Internal Server Error" |
| Success | "Document generated successfully." | "Document created." |
| Confirm delete | "Are you sure? This action cannot be undone." | "Delete?" |
| Form validation | "Phone number must be 11 digits." | "Invalid input." |

### Bangla Microcopy
All microcopy translated to Bangla with same tone. Professional Bangla (not overly formal, not slang).

## 13. ACCESSIBILITY

- All interactive elements keyboard accessible (Tab, Enter, Space, Arrow keys)
- Focus indicators: 2px primary ring, never :focus { outline: none } without replacement
- ARIA labels on icon-only buttons
- Color contrast: AA minimum (4.5:1 normal text, 3:1 large text)
- Form inputs associated with labels
- Error messages linked to inputs via aria-describedby
- Skip to content link (first focusable element)
- Announce dynamic updates via aria-live regions (toast, loading)
- Screen reader support for tables (scope, caption)
- Bangla screen reader support (compatible with popular screen readers)
